FutureTerm

Serial Port Helper

Why is this needed?

macOS only. This helper currently supports Mac only. iPad, iPhone, and Windows support is planned for a future release.

Some browsers (Safari, Firefox, etc.) don't support the WebSerial API, which FutureTerm uses to communicate with serial devices (Arduino, ESP32, flight controllers, etc.).

This helper runs a local WebSocket server on your machine that FutureTerm connects to. It listens on localhost only and shuts down automatically after 5 minutes of inactivity.

Installation

  1. Download FutureTerm-Helper.dmg using the button below
  2. Open the DMG (a disk image — it mounts like a USB drive). Drag FutureTerm.app to the Applications shortcut inside, or open Finder › Applications and drag it there. Then eject the DMG from your desktop.
  3. Go back to FutureTerm in your browser and click Connect
  4. When macOS asks to open FutureTerm, click Allow (first time only)

How it works

When you click Connect in FutureTerm:

  1. FutureTerm detects that WebSerial is not available
  2. It tries to connect to the local helper via WebSocket
  3. If the helper isn't running, it launches automatically via futureterm:// URL scheme
  4. The helper provides serial port access through a local TLS connection

Troubleshooting

macOS blocks the app? A notification may appear — click Open or Allow. If blocked, go to System Settings › Privacy & Security, scroll down to find FutureTerm, and click Open Anyway.

macOS asks for serial port access? Click Allow when macOS shows a Privacy & Security dialog asking if FutureTerm Helper can access serial devices. This is required to communicate with your device.

Connection fails? Make sure no other app is using port 9876. The helper listens on localhost:9876.

Want to uninstall? Simply delete FutureTerm.app from Applications. No background processes remain.
