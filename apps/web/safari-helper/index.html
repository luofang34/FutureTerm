FutureTerm

Safari & Firefox Serial Port Helper

Why is this needed?

Safari and Firefox don't support the WebSerial API, which FutureTerm uses to communicate with serial devices (Arduino, ESP32, flight controllers, etc.).

This lightweight helper app bridges the gap by running a local WebSocket server that FutureTerm connects to. It only runs when you're using FutureTerm and shuts down automatically after 5 minutes of inactivity.

Runs on localhost only · No network exposure · Auto-shutdown

Installation

  1. Download FutureTerm.dmg using the button below
  2. Open the DMG and drag FutureTerm.app to /Applications
  3. Go back to FutureTerm in your browser and click Connect
  4. When macOS asks to open FutureTerm, click Allow (first time only)

How it works

When you click Connect in FutureTerm on Safari/Firefox:

  1. FutureTerm detects that WebSerial is not available
  2. It tries to connect to the local helper via WebSocket
  3. If the helper isn't running, it launches automatically via futureterm:// URL scheme
  4. The helper provides serial port access through a secure local connection

Troubleshooting

macOS blocks the app? Go to System Settings > Privacy & Security, scroll down and click "Open Anyway".

Connection fails? Make sure no other app is using port 9876. The helper uses wss://127.0.0.1:9876.

Want to uninstall? Simply delete FutureTerm.app from Applications. No background processes remain.
